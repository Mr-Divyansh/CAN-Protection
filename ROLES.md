# Project Roles & Responsibilities

- **Product Owner**: Owns vision, MVP boundaries, accurate copy, and pending legal/vendor approvals.
- **UI/UX Designer**: Maintains fidelity to approved logo, palette, and 4 responsive/theme views.
- **Frontend Developer**: Implements accessible forms, theme switching, OTP flow, and confirmation dialogs.
- **Backend & Database Engineer**: Implements Express API validation, rate limits, session auth, SQLite/Supabase persistence, and PostgreSQL RLS migrations.
- **Security & QA Reviewer**: Audits threat boundaries and verifies unit, API, and browser journeys.
