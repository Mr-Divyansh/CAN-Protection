# CAN Protection — Design Specification

## Source of truth
Use the approved CAN Protection logo and the latest approved four-view UI reference from the project owner. Do not redraw or replace the logo without approval.

## Brand
- Name: CAN Protection
- Tagline: Protect Yourself. Stay Connected.
- Visual concept: shield + smartphone + call-protection signals.
- Style: premium, minimal, trustworthy cybersecurity product.

## Required layouts
1. Desktop — Dark Mode
2. Desktop — Light Mode
3. Mobile — Dark Mode
4. Mobile — Light Mode

## Main page sections
- Header: logo, Home, How It Works, Safety, About, theme toggle.
- Hero: “Take Control of Your Call Safety.”
- Number form: country code, phone input, Check Protection.
- Privacy reassurance.
- Status/result panel.
- How It Works: Enter number → Verify ownership → Activate/manage registration.
- Footer: Privacy Policy, Terms of Service, Contact.

## Status components
- Active: clear text label and green status indicator.
- Not registered/inactive: clear text and neutral/warning indicator.
- Deactivate: confirmation step.
- Errors: readable text; never rely on color alone.

## Responsive and accessibility rules
- Mobile-first responsive behavior; do not merely shrink desktop.
- Accessible labels, keyboard navigation, visible focus states, adequate contrast.
- Touch-friendly controls.
- Consistent spacing, typography, border radii, and button hierarchy.
- Avoid excessive glow, gradients, glassmorphism, and decorative clutter.

## Copy accuracy
Use “CAN Protection registration” or “registration status” for the MVP. Do not imply that registration alone blocks telecom calls.
